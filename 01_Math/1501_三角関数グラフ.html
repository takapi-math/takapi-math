各パラメータの意味と変形のルール

A 振幅 (Amplitude)

y軸方向（上下）への拡大・縮小を表します。

  • |A| > 1 : 上下に引き伸ばされる
  • 0 < |A| < 1 : 上下に押しつぶされる
  • A < 0 : x軸に関して上下が反転
k 周期係数 (Frequency)

x軸方向（左右）への伸縮を表し、周期が変化します。

  • sin, cos の周期: T = 2π / |k|
  • tan の周期: T = π / |k|
  • k > 1 : 波の密度が上がり、周期が短くなる
α x軸平行移動 (Phase Shift)

グラフ全体をx軸方向にどれだけ動かすかを表します。

  • α > 0 : 右方向へ α 移動
  • α < 0 : 左方向へ |α| 移動
  • 式が k(x - α) とマイナスになっている点に注意！
B y軸平行移動 (Vertical Shift)

グラフ全体をy軸方向に上下移動させます。

  • B > 0 : 上方向へ B 移動
  • B < 0 : 下方向へ |B| 移動
  • 波の振動の中心軸が y = B になります
