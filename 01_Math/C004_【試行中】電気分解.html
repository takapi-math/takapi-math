ポイント解説

電気分解では、**電源の正極につないだ電極が「陽極」**（酸化反応：電子を失う）、**負極につないだ電極が「陰極」**（還元反応：電子を受け取る）になります。

金属のイオン化傾向

陽イオンになりやすさの順序 (電気分解での陰極の反応に関係!)

定番の語呂合わせ:

「貸そうかな まぁあてにすな ひどすぎる借金」

(K Ca Na Mg Al Zn Fe Ni Sn Pb [H₂] Cu Hg Ag Pt Au)

小（単体として析出しやすい）

電気分解の陰極における重要ポイント

  • H₂ よりイオン化傾向が小さい金属イオン (Cu²⁺, Ag⁺ 等):
    水溶液中でも電子を受け取って金属単体として析出します。
  • H₂ よりイオン化傾向が大きい金属イオン (Na⁺, K⁺, Al³⁺ 等):
    水溶液中では水分子(H₂O)の方が電子を受け取りやすいため、金属は析出せず水素気体 (H₂) が発生します。

電気分解の反応ルール (優先順位)

どのような条件でどの物質が反応するかを決める完璧フローチャート

【陽極】酸化反応のルール (電子を出す)

  1. 電極自身をチェック:
    電極が Pt, C 以外 (Cu, Ag 等の金属) の場合 ➔ 電極自体が溶けてイオンになる！
    例: Cu → Cu²⁺ + 2e⁻
  2. 水溶液中の陰イオンをチェック (電極が Pt, C の場合):
    ・ハロゲン化物イオン (Cl⁻, I⁻) がある ➔ ハロゲン単体が発生！
    例: 2Cl⁻ → Cl₂ + 2e⁻
    ・それ以外 (SO₄²⁻, NO₃⁻ や 水溶液のH₂O/OH⁻) ➔ 水(またはOH⁻)が酸化されて酸素 O₂ が発生！
    塩基性: 4OH⁻ → 2H₂O + O₂ + 4e⁻
    酸性/中性: 2H₂O → O₂ + 4H⁺ + 4e⁻

【陰極】還元反応のルール (電子をもらう)

  1. 水溶液中の陽イオンをチェック:
    ・イオン化傾向が H₂ より小さい金属イオン (Cu²⁺, Ag⁺) ➔ 金属が析出！
    例: Cu²⁺ + 2e⁻ → Cu
    ・イオン化傾向が H₂ より大きい金属イオン (Na⁺, K⁺, Mg²⁺, Al³⁺等) ➔ 水(またはH⁺)が還元されて水素 H₂ が発生！
    酸性: 2H⁺ + 2e⁻ → H₂
    中性/塩基性: 2H₂O + 2e⁻ → H₂ + 2OH⁻
