なぜ f + k·g = 0 は交点を通るのか？

直線 $f: a_1x + b_1y + c_1 = 0$ と 直線 $g: a_2x + b_2y + c_2 = 0$ の交点を $(x_i, y_i)$ とすると、 この点はどちらの式も満たすため、f(x_i, y_i) = 0 かつ g(x_i, y_i) = 0 となります。

新しい方程式 f(x,y) + k · g(x,y) = 0 に $(x_i, y_i)$ を代入すると： 0 + k · 0 = 0 となり、$k$ の値が何であっても恒等的に成立します。したがって、この方程式が表す直線は必ず2直線の交点を通ります。

注意: この表現では、$k$ をどんな値にしても直線 g(x,y) = 0 そのものを表すことはできません（$k \to \pm\infty$ の極限にあたるため）。
