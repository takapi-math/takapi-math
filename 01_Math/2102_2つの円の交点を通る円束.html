なぜ f + k·g = 0 は交点を通るのか？

2つの円 $f: x^2 + y^2 + l_1x + m_1y + n_1 = 0$ と $g: x^2 + y^2 + l_2x + m_2y + n_2 = 0$ の交点を $(x_i, y_i)$ とすると、 この点はどちらの円周上にもあるため、f(x_i, y_i) = 0 かつ g(x_i, y_i) = 0 となります。

新しい方程式 f(x,y) + k · g(x,y) = 0 に $(x_i, y_i)$ を代入すると： 0 + k · 0 = 0 となり、$k$ の値に関わらず常に成立します。したがって、この方程式が表す図形は必ず2つの円の交点を通ります。

k ≠ -1 のとき (円):
$x^2 + y^2$ の係数が $(1+k)$ となり、$1+k \neq 0$ なので両辺を割ることで円の方程式になります。中心は2円の中心を結ぶ線分上に位置します。
k = -1 のとき (根軸 - 直線):
$x^2 + y^2$ の項が相殺されて消去され、$x, y$ の1次方程式（直線）になります。この直線は2円の交点を通る直線（根軸）と呼ばれます。
