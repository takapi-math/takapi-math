頂点 P の軌跡の方程式
$y = -x^2 + 3x$

動点 P(x, y) の軌跡を求める手順

  1. 平方完成: 2次関数を $y = a(x - p)^2 + q$ の形に変形し、頂点座標をパラメータ $t$ で表す。
  2. 動点 $P(x, y)$ とおく: 頂点の座標を大文字 $X, Y$ ではなく動点 $P(x, y)$ とおく。
    x = (tの式), \quad y = (tの式)
  3. パラメータ $t$ の消去: $x = \dots$ から $t = \dots$ の形を作り、$y = \dots$ に代入して $x$ と $y$ のみの関係式を導く。
  4. $x$ の変域の計算: パラメータ $t$ に範囲制限（例: $-5 \le t \le 5$ や $t \ge 0$）がある場合、$x = g(t)$ を用いて $x$ の動き得る範囲（変域）を不等式計算で求める。
  5. 結論の記述: 「軌跡は 放物線 $y = f(x)$ ($a \le x \le b$)」のようにグラフの種類と変域を明記する。

$t$ の範囲制限がある場合の $x$ の変域計算

例えば $x = 2t$ かつ $-5 \le t \le 5$ の場合、$t = \frac{x}{2}$ より $-5 \le \frac{x}{2} \le 5$ となり、各辺に $2$ を掛けて $-10 \le x \le 10$ と計算できます。

シミュレーターの使い方

  • パラメータ $t$ スライダー: $t$ の値を動かすことで、2次関数のグラフの変化と頂点の移動が確認できます。
  • 再生/停止ボタン: $t$ を自動的にアニメーション変化させます。
  • 放物線/軌跡線切り替え: 移動する2次関数そのものの表示や、頂点が通った後にできる軌跡（放物線や直線）の表示を切り替えます。
  • キャンバス操作: マウスドラッグで表示位置を移動、ホイール回転で拡大・縮小できます。
  • 下部解説パネル: 各プリセット問題における頂点座標の求め方と $t$ の消去手順を段階的に詳しく解説しています。
